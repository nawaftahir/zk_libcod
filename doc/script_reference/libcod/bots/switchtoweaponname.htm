self switchToWeaponName( <weaponName> )

Module: Bots

Summary:

Convenience wrapper combining weaponNameToId + switchToWeaponId in a single call. Looks up the weapon index for weaponName and sets it as the bot's active weapon (writes customPlayerState[id].botWeapon, same field switchToWeaponId uses).

Returns false if the weapon name is unknown (index 0) without changing state. Errors if self is not a bot or the entity number is out of range.



Example:

if (!self switchToWeaponName("mp44_mp"))
    self iprintln("unknown weapon");



Required Args:

  • 1 : <weaponName> Weapon file name string (e.g. "kar98k_mp", "mp44_mp").

Returns:

Boolean true on success. Boolean false if weaponName is unknown. Stack-errors and returns undefined if self is not a bot.
