self clearBotInputs()

Module: Bots

Summary:

Wipes all persistent bot input state for the calling bot in a single call:

  • botForwardMove = 0 (stops walking forward or backward)
  • botRightMove = 0 (stops strafing)
  • botButtons = 0 (releases every held button: jump, crouch, prone, lean left, lean right, fire, melee, frag, smoke, use, ADS)

Bot inputs in libcod are persistent: setBotStance("prone") leaves the prone bit set until you flip it back, setLean("left") keeps leaning until cleared, fireWeapon(1) keeps the trigger held until fireWeapon(0). If a bot dies mid-action, the next life starts with those buttons still pressed.

Call this once on each respawn (waittill "spawned_player") so every life starts at a clean neutral state.

Errors if called on a non-bot or an entity number outside MAX_CLIENTS.



Example:

respawn_input_reset()
{
    self endon("disconnect");
    for (;;)
    {
        self waittill("spawned_player");
        self clearBotInputs();
    }
}



Required Args:

None.


Returns:

Boolean true on success. Stack-errors and returns undefined if self is not a bot or the entity number is out of range.
