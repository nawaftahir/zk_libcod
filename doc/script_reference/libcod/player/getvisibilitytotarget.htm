self getVisibilityToTarget( <target>, [contentMask] )

Module: Player

Summary:

Bitmask indicating which of four body points on target are visible from self's eye position.

  • bit 0 (value 1) = head visible
  • bit 1 (value 2) = chest visible
  • bit 2 (value 4) = waist visible
  • bit 3 (value 8) = feet visible

Returns 0 if no body point is visible, 15 if all four are. The four points are Z-offsets above target.origin (head=+60, chest=+48, waist=+24, feet=+0). DEFAULT_VIEWHEIGHT in CoD2 is 60, so the offsets line up with a standing target. A crouched target's actual viewheight is 40 and a prone target's is 11, so the upper points float above the actual body for those stances. Useful for "is the silhouette exposed" decisions but not pixel-accurate against the hitbox. Use getVisibilityToTargetBones if stance matters.

Each point runs a G_LocationalTrace from self's view origin. self is the ignored entity (the eye sits at the top of the standing hitbox so otherwise the trace would immediately self-collide). A sample point counts as visible if the trace reached its full distance OR if it stopped on the target's own body -- the second branch covers body-inclusive content masks where the trace stops at the target body surface just before the sample.

One call replaces four separate bulletTracePassed / sightTracePassed calls plus the wiring to pack the result.



Example:

mask = self getVisibilityToTarget(enemy);

// bit 0 = head -- if exposed, fire
if (mask & 1)
    self fireWeapon(1);
else if (mask == 0)
    self fireWeapon(0);   // nothing visible, hold fire

// Head plus chest plus waist visible at minimum
if (mask >= 7)
    self iprintln("good shot");

// With explicit mask -- only solid world blocks
worldMask = 1;
mask = self getVisibilityToTarget(enemy, worldMask);



Required Args:

  • 1 : <target> The entity to test visibility on. Usually a player; any in-use entity with a valid currentOrigin works.

Optional Args:

  • 2 : <contentMask> Trace content mask. Defaults to MASK_OPAQUE_AI minus CONTENTS_BODY (0x801803 / 8395267) -- world solids + foliage + sky block; entity bodies (self, target, bystanders) do not. Pass MASK_SHOT (0x2802831) for body-inclusive behaviour, or 1 for solid world only.

Returns:

Integer bitmask 0..15. Stack-errors and returns undefined on argument error or if the target entity is not in use.
