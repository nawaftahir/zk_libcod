self getVisibilityToTargetBones( <target>, [contentMask] )

Module: Player

Summary:

Bitmask indicating which actual model bones on target are visible from self's eye position. Unlike getVisibilityToTarget which samples four fixed Z-offsets above the entity origin, this native uses G_DObjGetWorldTagPos to read real bone world positions. That makes it accurate against crouched and prone targets whose hitbox sits below a standing silhouette.

Covers every CoD2 hit-location group in eight bits. Head, neck, upper torso (j_spine4) and lower torso (j_spine1) each get a single trace. Arms and legs each get three sample joints (proximal, middle, distal) and the limb bit is set on the first joint that reaches, so any visible part of an arm or leg sticking around cover registers.

  • bit 0 (value 1) = j_head | HITLOC HEAD, HELMET
  • bit 1 (value 2) = j_neck | HITLOC NECK
  • bit 2 (value 4) = j_spine4 | HITLOC TORSO_UPR
  • bit 3 (value 8) = j_spine1 | HITLOC TORSO_LWR
  • bit 4 (value 16) = j_shoulder_le or j_elbow_le or j_wrist_le | HITLOC L_ARM_UPR, L_ARM_LWR, L_HAND
  • bit 5 (value 32) = j_shoulder_ri or j_elbow_ri or j_wrist_ri | HITLOC R_ARM_UPR, R_ARM_LWR, R_HAND
  • bit 6 (value 64) = j_hip_le or j_knee_le or j_ankle_le | HITLOC L_LEG_UPR, L_LEG_LWR, L_FOOT
  • bit 7 (value 128) = j_hip_ri or j_knee_ri or j_ankle_ri | HITLOC R_LEG_UPR, R_LEG_LWR, R_FOOT

Bones that do not exist on the target's model (e.g. a non-player entity) silently skip and that bit stays 0. Worst case is sixteen traces; arm/leg checks early-out on the first joint that reaches.

Each trace runs G_LocationalTrace from self's view origin with self as the ignored entity (the eye sits inside self's standing bbox -- without this the trace would self-collide). A bone counts as visible if the trace reached its position OR if it stopped on the target's own body (the latter handles body-inclusive content masks where the trace stops at the target body surface just before the bone).

Use this instead of getVisibilityToTarget when stance matters, when you need to distinguish head exposure from neck exposure for helmet logic, or when arm/leg-only exposure is the deciding factor.



Example:

mask = self getVisibilityToTargetBones(enemy);

// Head exposed -> fire
if (mask & 1)
    self fireWeapon(1);

// Helmet area only (neck blocked but head visible) -> aim a bit lower
helmet_only = (mask & 1) && !(mask & 2);

// Only legs visible -> probably hiding upper body behind low cover
only_legs = (mask & 192) && !(mask & 15);

// Arm peeking around right side
peeking = (mask & 32) && !(mask & 7);



Required Args:

  • 1 : <target> The entity to test bone visibility on. Must have a player-like model for all bones to resolve; otherwise some bits will stay 0.

Optional Args:

  • 2 : <contentMask> Trace content mask. Defaults to MASK_OPAQUE_AI minus CONTENTS_BODY (0x801803 / 8395267) -- world solids + foliage + sky block; entity bodies do not. Pass MASK_SHOT (0x2802831) for body-inclusive behaviour.

Returns:

Integer bitmask 0..255. Stack-errors and returns undefined on argument error or if the target entity is not in use.
