strReplace( <source>, <search>, <replacement> )

Module: System

Summary:

Returns a copy of source with every occurrence of the substring search replaced by replacement (case-sensitive, non-overlapping, left to right). An empty search string is a no-op.



Example:

strReplace("Hi {name}", "{name}", "Nerd"); // "Hi Nerdy"
strReplace("a.b.c", ".", "-");             // "a-b-c"



Required Args:

  • 1 : <source> (string) The string to search in
  • 2 : <search> (string) The substring to find
  • 3 : <replacement> (string) What to replace each match with (may be empty to delete)
