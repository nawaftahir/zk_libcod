isStringFloat( <string> )

Module: System

Summary:

Returns true if the string is a valid floating-point number: an optional sign, digits and at most one dot, with at least one digit. Note that an integer string is also a valid float (42 is 42.0), so isStringInt is a subset of isStringFloat; for a strict decimal check use isStringFloat(s) && !isStringInt(s).



Example:

isStringFloat("3.14"); // true
isStringFloat("42");   // true (42 is 42.0)



Required Args:

  • 1 : <string> (string) The string to test
