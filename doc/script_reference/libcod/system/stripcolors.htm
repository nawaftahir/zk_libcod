stripColors( <string> )

Module: System

Summary:

Returns a copy of the string with all color codes removed. Uses the engine's own name cleaning (I_CleanStr), so the result matches exactly how CoD2 strips names for comparison and display - useful for name checking and banned-name matching.



Example:

clean = stripColors(name); // "^1Ne^7rdy" -> "Nerdy"



Required Args:

  • 1 : <string> (string) The string to process
