sha256( <string>, [<iterations>] )

Module: System

Summary:

Returns the SHA-256 hash of the string as a 64-character lowercase hex string. The optional second argument re-hashes the hex digest that many times (key stretching, useful for password storage). Self-contained, no external library.



Example:

sha256("abc");            // "ba7816bf...15ad"
sha256("password", 5000); // stretched 5000 times



Required Args:

  • 1 : <string> (string) The string to hash


Optional Args:

  • 2 : <iterations> (int, default 1) Number of times to hash (must be >= 1)
