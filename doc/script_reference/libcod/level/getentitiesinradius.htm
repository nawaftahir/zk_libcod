getEntitiesInRadius( <origin>, <radius>, [classFilter] )

Module: Level

Summary:

Returns an array of all in-use entities whose currentOrigin lies within the given radius of origin. The optional third arg restricts results to a single classname (e.g. "grenade", "weapon_dropped", "trigger_use").

Iterates only the active entity range (level.num_entities) and uses squared-distance comparison; no sqrt is taken. Skips entities with the inuse flag cleared.

Errors and returns undefined if radius is negative or any arg has the wrong type.



Example:

// All entities within 256 units
nearby = getEntitiesInRadius(self.origin, 256);

// Only live grenades within 400 units (blast pre-check)
threats = getEntitiesInRadius(self.origin, 400, "grenade");

// Dropped weapons within reach
loot = getEntitiesInRadius(self.origin, 96, "weapon_dropped");



Required Args:

  • 1 : <origin> World-space query point.
  • 2 : <radius> Maximum distance in units. Must be >= 0; squared internally for comparison.

Optional Args:

  • 3 : <classFilter> Only entities with this classname are returned. Pass undefined for any classname.

Returns:

Array of matching entities. Empty array if none match. Undefined on argument error.
