getClosestPlayerInRange( <origin>, [maxDistSq], [filterTeam], [contentMask] )

Module: Level

Summary:

Returns the closest alive, playing client to origin, measured from each player's body origin (currentOrigin). Returns undefined if no client matches.

Iterates only the client slot range and uses squared-distance comparison.

Use this for proximity queries: grenade splash, AOE healing, "who is standing on top of me". For perception-style queries where the eye position matters, prefer getClosestPlayerByViewOriginInRange.



Example:

// Closest teammate within 500 units (squared) for friendly-fire avoidance
mate = getClosestPlayerInRange(self.origin, 500 * 500, my_team);
if (isDefined(mate) && mate != self)
    return; // teammate too close, hold fire



Required Args:

  • 1 : <origin> World-space query point.

Optional Args:

  • 2 : <maxDistSq> Squared distance cap. Pass undefined for unlimited range.
  • 3 : <filterTeam> Only clients on this team. 0=FREE, 1=AXIS, 2=ALLIES, 3=SPECTATOR. Pass undefined or a negative integer for any team.
  • 4 : <contentMask> If set, runs a locational trace from origin to each candidate's currentOrigin with this mask before counting it.

Returns:

Closest matching player entity, or undefined if no client matches.
