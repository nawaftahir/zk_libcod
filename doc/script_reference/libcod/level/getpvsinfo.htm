getPVSInfo( <origin1>, <origin2> )

Module: Level

Summary:

Debug sibling of getPVS. Same underlying lookup (BSP leaf -> cluster -> cluster PVS bitvector) but returns a script struct with all of the intermediate state so the caller can see exactly why the engine returned the answer it did.

Use this when getPVS is reporting unexpected results to determine whether: (a) the map shipped without a compiled visibility lump, (b) one or both origins sit outside the BSP playable volume, or (c) the result is a real "this cluster cannot see that cluster."

  • visible : 1 if origin2 is potentially visible from origin1's cluster, 0 otherwise. Identical to getPVS.
  • cluster1 : Cluster index of origin1 (-1 if outside BSP / sky / void).
  • cluster2 : Cluster index of origin2 (-1 if outside BSP / sky / void).
  • numClusters : Total cluster count for the loaded BSP (cm.numClusters). 0 means no clusters loaded at all.
  • vised : 1 if the BSP shipped a real LUMP_VISIBILITY (cm.vised). 0 means no visibility was compiled into the .d3dbsp; every getPVS will return 1 (fail-open).
  • fallback : 1 if the answer came from the fail-safe path (invalid cluster OR vised=0). Use this to tell a real "visible" from a "we had to guess visible."

The two failure modes to look for:

  • fallback=1 AND vised=0 -> the map was compiled without visibility data. getPVS is useless on this map; every call returns 1.
  • fallback=1 AND vised=1 -> one or both points are outside the BSP (above the sky brush, inside void, inside a solid brush). Move the sample point to a legal eye/origin.



Example:

info = getPVSInfo(self getViewOrigin(), enemy getViewOrigin());

self iprintln("PVS: vis=" + info.visible + " c1=" + info.cluster1 + " c2=" + info.cluster2 + " of " + info.numClusters);

if (!info.vised)
    self iprintln("WARN: BSP has no visibility lump, PVS is fail-open");
else if (info.fallback)
    self iprintln("WARN: one or both origins outside BSP (cluster=-1)");



Required Args:

  • 1 : <origin1> First world-space point.
  • 2 : <origin2> Second world-space point.

Returns:

Struct with keys: visible (int 0/1), cluster1 (int), cluster2 (int), numClusters (int), vised (int 0/1), fallback (int 0/1). Stack-errors and returns undefined on argument error.
