getPlayersByViewOriginInRange( <origin>, [maxDistSq], [filterTeam], [traceContentMask], [ignoreEnt] )

Module: Level

Summary:

Returns an array of all alive, playing clients whose view origin (eye position via G_GetPlayerViewOrigin) lies within the squared distance of origin. Optional filters narrow by team and by line of sight.

Array variant of getClosestPlayerByViewOriginInRange. Useful when every visible target matters: counting threats, perception sweeps, suppression awareness.



Example:

my_eye     = self getViewOrigin();
enemy_team = 1;
mask       = 524545; // MASK_OPAQUE

threats = getPlayersByViewOriginInRange(my_eye, view_dist_sq, enemy_team, mask);
self.bot_visible_threats = threats.size;



Required Args:

  • 1 : <origin> World-space query point.

Optional Args:

  • 2 : <maxDistSq> Squared distance cap. Pass undefined for unlimited range.
  • 3 : <filterTeam> Only clients on this team. 0=FREE, 1=AXIS, 2=ALLIES, 3=SPECTATOR. Pass undefined or a negative integer for any team.
  • 4 : <traceContentMask> If set, runs a locational trace from origin to each candidate's view origin with this mask. Only players the trace reaches are returned.
  • 5 : <ignoreEnt> If set, this entity is skipped during the scan. Use self to exclude the caller from its own proximity query.

Returns:

Array of matching player entities. Empty array if none match.
