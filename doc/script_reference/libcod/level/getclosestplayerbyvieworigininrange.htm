getClosestPlayerByViewOriginInRange( <origin>, [maxDistSq], [filterTeam], [traceContentMask], [ignoreEnt] )

Module: Level

Summary:

Returns the closest alive, playing client to origin, measured from each player's view origin (eye position via G_GetPlayerViewOrigin). Returns undefined if no client matches.

Use this for perception-style queries where the eye, not the body, is the meaningful reference. Combined with traceContentMask, a single call yields the closest LOS-visible enemy within range.



Example:

my_eye     = self getViewOrigin();
enemy_team = 1; // axis if I'm allies
mask       = 524545; // MASK_OPAQUE: solid + glass + slime

// Closest LOS-visible enemy from my eye, within squared view distance
target = getClosestPlayerByViewOriginInRange(my_eye, 2200 * 2200, enemy_team, mask);
if (isDefined(target))
    self.bot_enemy = target;



Required Args:

  • 1 : <origin> World-space query point. Usually the caller's view origin.

Optional Args:

  • 2 : <maxDistSq> Squared distance cap. Pass undefined for unlimited range.
  • 3 : <filterTeam> Only clients on this team. 0=FREE, 1=AXIS, 2=ALLIES, 3=SPECTATOR. Pass undefined or a negative integer for any team.
  • 4 : <traceContentMask> If set, runs a locational trace from origin to each candidate's view origin with this mask before counting it. Use to require line of sight.
  • 5 : <ignoreEnt> If set, this entity is skipped during the scan. Use self to exclude the caller from its own proximity query.

Returns:

Closest matching player entity, or undefined if no client matches.
