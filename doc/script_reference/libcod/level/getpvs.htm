getPVS( <origin1>, <origin2> )

Module: Level

Summary:

O(1) Potentially-Visible-Set lookup between two world points. Returns 1 if the BSP says origin2 lies in the PVS of origin1's leaf, else 0. Designed to run BEFORE expensive sightTracePassed / bulletTrace calls.

A return of 0 is authoritative: the points cannot see each other and any sight trace will fail. A return of 1 means "potentially visible" - the caller still needs a real trace to confirm line of sight.

If either origin's cluster is out of bounds (negative, outside the playable area, above the sky brush, in map void, or beyond cm.numClusters), the function returns 1 as a fail-safe so the caller's expensive trace still runs. Use getPVSInfo if you need to distinguish a real "visible" from this fail-open path.



Example:

my_eye    = self getViewOrigin();
other_eye = other getViewOrigin();

if (!getPVS(my_eye, other_eye))
    return; // cannot possibly see other; skip the sight trace

if (!sightTracePassed(my_eye, other_eye, false, self))
    return; // PVS said maybe, trace confirms blocked

// other is visible



Required Args:

  • 1 : <origin1> First world-space point. Typically the observer's eye or origin.
  • 2 : <origin2> Second world-space point. Typically the target's eye or origin.

Returns:

Integer 1 if origin2 is potentially visible from origin1, 0 otherwise.
