getPlayersInRange( <origin>, [maxDistSq], [filterTeam], [contentMask], [ignoreEnt] )

Module: Level

Summary:

Returns an array of all alive, playing clients within the given squared-distance of origin. Optional filters narrow the result by team and by line of sight.

Iterates only the client slot range (sv_maxclients) and uses squared-distance comparison; no sqrt is taken.

The optional contentMask runs G_LocationalTracePassed between origin and each candidate's currentOrigin. Only players the trace reaches are included. The trace ignores each candidate's own entity, so the candidate's body never blocks its own visibility check.



Example:

// All alive players within 500 units (squared)
nearby = getPlayersInRange(self.origin, 500 * 500);

// All axis-team players, any distance
axis = getPlayersInRange((0, 0, 0), undefined, 1);

// All allies visible from a grenade origin via MASK_SHOT (0x2000B01)
mask    = 33558785;
victims = getPlayersInRange(grenade.origin, blast_r * blast_r, 2, mask);



Required Args:

  • 1 : <origin> World-space query point.

Optional Args:

  • 2 : <maxDistSq> Squared distance cap. Pass undefined for unlimited range.
  • 3 : <filterTeam> Only clients on this team. 0=FREE, 1=AXIS, 2=ALLIES, 3=SPECTATOR. Pass undefined or a negative integer for any team.
  • 4 : <contentMask> If set, runs a locational trace from origin to each candidate's currentOrigin with this mask. Only players the trace reaches are returned.
  • 5 : <ignoreEnt> If set, this entity is skipped during the scan. Use self to exclude the caller from its own proximity query.

Returns:

Array of matching player entities. Empty array if none match.
