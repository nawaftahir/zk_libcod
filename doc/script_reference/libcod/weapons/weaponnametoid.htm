weaponNameToId( <weaponName> )

Module: Weapons

Summary:

Returns the engine weapon index for a given weapon file name (e.g. "mp44_mp", "kar98k_mp"), or 0 if the name is unknown.

Pairs with the bot script method switchToWeaponId so callers don't have to hardcode or guess weapon ids. Useful for waypoint files, bot loadouts, and any data layer that names weapons by string.

Errors and returns undefined if weaponName is undefined or has the wrong type.



Example:

id = weaponNameToId("mp44_mp");
if (id > 0)
    bot switchToWeaponId(id);



Required Args:

  • 1 : <weaponName> Weapon file name string (the same name used in weapondefs/, e.g. "kar98k_mp").

Returns:

Integer engine weapon index. 0 if the name is unknown. Undefined on argument error.
